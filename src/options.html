Setup checklist

ChromeOS settings that bring it closer to tide. tico can't change them for you, so each says where to go; tick them off as you go. The ticks stay on this Chromebook.

    Keys

    Chrome binds four keys when tico installs; the rest you bind once at chrome://extensions/shortcuts. This list says which are still to do, and updates when you come back.

    CommandKeyBound to

    Apps

    Each key opens a new window of its app on the current workspace. Chrome fixes the keys; you choose the apps. Change a key at chrome://extensions/shortcuts.

    KeyNameAddress

    Attention

    tico marks a window when a site's unread count goes up in its title. Gmail, Chat and Calendar are always watched; add others here. Each needs access to its site, asked for on this Chromebook when you add it.

      Dim

      How dark the dim makes the windows you're not in, when it's on (turn it on from the dashboard).

      Mouse on this Chromebook

      A longer step per wheel click than Settings offers, set from crosh (Ctrl+Alt+T), which needs chrome://flags/#gesture-properties-dbus-service enabled once. ChromeOS forgets it at each reboot, so with a step here, tico opens a page with the lines to copy at each login. Leave it empty for no reminder.

      Import and export

      The settings as JSON, in the shape of tide's config, to copy between machines or keep in a dotfiles repo.
